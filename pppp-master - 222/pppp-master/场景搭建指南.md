# CoppeliaSim 配电房场景搭建指南（4.10.0）

> 目标：在 CoppeliaSim 4.10.0 里搭出「机器人 + 3 点位 + 6 类目标 + 2 障碍物」的配电房场景，
> 对象命名与 `inspection/config.py` 完全一致，使 M1 代码能直接跑通。

---

## 零、最终场景结构树（对照检查用）

```
/ (场景根)
├─ P3DX                     # 机器人底座
│   ├─ leftMotor            # 左轮关节（P3-DX 自带，重命名）
│   ├─ rightMotor           # 右轮关节（P3-DX 自带，重命名）
│   ├─ VisionSensor         # 视觉传感器（相机，attach 到机器人）
│   ├─ Hokuyo               # 激光雷达（attach 到机器人）
│   └─ proxFront            # 前方接近传感器（attach 到机器人）
├─ waypoint_01 / 02 / 03    # 巡检点位（dummy）
├─ cabinet_01 / 02 / 03     # 配电柜
├─ meter_01                 # 指针仪表
├─ lamp_green / lamp_red    # 指示灯（绿/红）
├─ sign_01                  # 安全警示标识
├─ switch_01                # 开关/旋钮
├─ obstacle_01 / obstacle_02# 障碍物
└─ (floor / wall_xx)        # 地板与墙体（可选，命名自由）
```

---

## 一、新建场景与地板

1. 打开 CoppeliaSim，`File > New scene`。
2. 添加地板：菜单 `Add > Primitive shape > Plane`，在属性里把尺寸调大（如 X=8m、Y=6m），作为地面。
3. （可选）`Add > Primitive shape > Cuboid` 摆几条长条墙体，围出「巡检通道 + 设备区」的布局。

---

## 二、放置机器人 Pioneer P3-DX

1. 打开模型浏览器（若左侧没有，点工具栏的模型浏览器图标，或菜单 `Modules > Model browser`）。
2. 搜索 `Pioneer` 或在 `robots > mobile` 分类里找到 **Pioneer P3-DX**，拖入场景。
   - 目录参考：`models/robots/mobile/Pioneer P3DX.ttm`
3. 在场景层次（Scene Hierarchy）里：
   - 把机器人根对象重命名为 **`P3DX`**。
   - 找到它的两个轮子关节（默认名类似 `Pioneer_p3dx_leftMotor` / `Pioneer_p3dx_rightMotor`），
     分别重命名为 **`leftMotor`**、**`rightMotor`**（保持它们是 P3DX 的子对象）。
4. 选中机器人，用 `Move` 工具把它放到场景起点，注意轮子贴地。

---

## 三、加装激光雷达 Hokuyo

1. 模型浏览器搜索 `Hokuyo`，找到 **fast Hokuyo URG-04LX**，拖入场景。
   - 目录参考：`models/sensors/Hokuyo URG 04LX UG01 fast.ttm`
2. 在场景层次里，把它**拖到 `P3DX` 下成为子对象**（这样雷达随机器人移动）。
3. 重命名为 **`Hokuyo`**。
4. 调整位置到机器人顶部（如 z≈0.2m），朝向机器人前进方向，扫描平面保持水平。

---

## 四、加装视觉传感器 VisionSensor

1. 菜单 `Add > Vision sensor > Perspective type`。
2. 在场景层次里，把它拖到 `P3DX` 下成为子对象，重命名为 **`VisionSensor`**。
3. 摆到机器人前上方（如前方 0.1m、高 0.3m），**镜头朝机器人前进方向**。
4. 双击该 vision sensor，设置分辨率（建议 640x480），并勾选 `Explicit handling`（显式处理，便于 ZMQ 抓帧）。
5. **M1 阶段**：固定朝前即可。**M2+ 云台扩展**：可在相机下加一个绕 Z 轴的 revolute joint，实现停靠后转向对准目标。

---

## 五、加装前方接近传感器 proxFront

1. 菜单 `Add > Proximity sensor > Cone type`（圆锥型，检测前方锥形区域）。
2. 拖到 `P3DX` 下成为子对象，重命名为 **`proxFront`**。
3. 摆到机器人最前端，检测方向朝前进方向，检测距离约 0.35m（急停保护距离）。

---

## 六、设置 3 个巡检点位（dummy）

1. 菜单 `Add > Dummy`，添加 3 个，分别重命名为 **`waypoint_01` / `waypoint_02` / `waypoint_03`**。
2. 按巡检顺序摆放到：
   - **waypoint_01**：进线柜区（配电柜 cabinet_01 前方约 1m 处，相机能正对柜体）
   - **waypoint_02**：仪表/指示灯区（meter_01、lamp_green、lamp_red 前方约 1m）
   - **waypoint_03**：开关/警示区（switch_01、sign_01 前方约 1m）
3. 点位朝向不重要（dummy 只提供位置坐标），关键是**机器人停在该处时相机能看清对应目标**。

---

## 七、放置 6 类目标

> 目标用「primitive shape」拼出外观，注意**颜色特征明显**（利于后续 YOLO 识别和颜色判读）。

### 1) 配电柜 cabinet_01~03（3 个）
- `Add > Primitive shape > Cuboid`，尺寸约 0.8m(宽) x 0.4m(深) x 1.6m(高)，重命名 `cabinet_01`。
- 复制两份，重命名 `cabinet_02`、`cabinet_03`，摆在不同位置（柜体排列规则）。
- 颜色建议：深灰柜体；前面板可加一个浅色小 cuboid 当**编号牌**（后续 M3 做 OCR 识别编号）。

### 2) 指针仪表 meter_01
- 表盘：`Add > Primitive shape > Cylinder`，压扁成圆盘（半径约 0.15m），重命名 `meter_01`。
- 指针：再放一个细长 cuboid（如 0.02 x 0.12 x 0.005m），放在表盘中心，作为指针。
  - 后续可让指针绕 Z 轴旋转来模拟「读数超限」异常。
- 颜色：白色表盘 + 黑色刻度/红色指针。

### 3) 指示灯 lamp_green / lamp_red
- `Add > Primitive shape > Sphere`（或小圆柱），半径约 0.03m。
- 重命名 **`lamp_green`**（绿色）、**`lamp_red`**（红色）。
- 亮灭模拟：M4 阶段用脚本改 emissive 颜色/亮度；M1 先静态摆放。
- 放置位置：仪表区，两个灯相邻，便于一次抓帧同时判读。

### 4) 安全警示标识 sign_01
- 用 cuboid 拼一个黄色警示牌，或 `Add > Primitive shape > Disc` 做圆形标识。
- 重命名 **`sign_01`**，放在开关区醒目位置。
- 颜色建议：黄底（高辨识度），可加黑色边框纹理。

### 5) 开关/旋钮 switch_01
- 旋钮式：小圆柱 + 顶部指示线（细长 cuboid）。
- 或拨杆式：细长 cuboid 绕轴可旋转。
- 重命名 **`switch_01`**，颜色建议：深色主体 + 亮色指示端（便于位置判读）。

### 6) 障碍物 obstacle_01 / obstacle_02
- `Add > Primitive shape > Cuboid`（模拟物料箱/工具箱），尺寸约 0.4 x 0.3 x 0.3m。
- 重命名 **`obstacle_01`**（静态，放在通道一侧，机器人需绕行）。
- 重命名 **`obstacle_02`**（动态）：M1 先放在通道旁备用位置，M6 阶段用脚本在任务中途把它移到通道中央，模拟「临时出现」。

---

## 八、检查与保存

1. 打开场景层次，逐项对照「零、最终场景结构树」，确认：
   - [ ] 机器人及 5 个传感器都在 `P3DX` 下（父子关系正确）
   - [ ] 3 个点位、6 类目标、2 个障碍物命名与 `config.py` 完全一致
   - [ ] 相机/雷达/接近传感器朝向正确
2. `File > Save scene as`，保存为如 `配电房巡检场景.ttt`。
3. 打开场景后保持运行（M1 代码连接时场景需处于打开状态，无需手动点仿真运行，代码会 `startSimulation`）。

---

## 九、常见问题

| 问题 | 处理 |
|---|---|
| 代码报 handle=-1 | 对象名不匹配，检查命名是否与 config.py 一致（注意大小写、下划线） |
| 抓帧图像全黑 | 相机朝向不对 / 未勾选 Explicit handling / 相机嵌在墙里 |
| 机器人不动 | 左右轮关节名不对，或轮速设置被关节模式覆盖（确认关节为 torque/velocity 模式） |
| LiDAR 读不到数据 | Hokuyo 朝向错误，或激光接口 API 在 4.10.0 需用 `readLidar`（代码已做兼容） |
| 机器人停靠时相机看不清目标 | 调整 waypoint 位置，使相机正对目标约 0.8~1.2m 距离 |
